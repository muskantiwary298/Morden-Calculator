# 🧮 Modern Calculator

A simple and modern calculator web application built using HTML, CSS, and JavaScript. It features a clean user interface and supports basic mathematical operations.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Percentage calculations
- Clear All (AC) and Delete (DEL) buttons
- Responsive design
- Modern dark theme UI
- Error handling for invalid calculations

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript** – Calculator functionality

## 📂 Project Structure

```text
Modern-Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code.

The calculator includes a dark-themed interface with interactive buttons and a display screen.
